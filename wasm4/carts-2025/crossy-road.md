# Crossy Road

This is a simple clone of the classic game **Crossy Road**, made with the **WASM-4** engine using the **Go** language.

The objective of the game is to cross the street dodging cars and collecting coins to increase your score. The game restarts after each collision.

## Controls

- ⬆️ / ⬇️ / ⬅️ / ➡️ — move the character
- Ⓧ (X button) — start or restart the game
